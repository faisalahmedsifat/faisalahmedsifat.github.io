Selected systems work

Tensorify

Visual workflow compiler for AI pipelines

Problem

Teams need a way to compose AI workflows visually without giving up execution discipline or deployment realism.

What I built

A visual node graph compiler that transpiles workflows into Python pipelines, backed by dedicated execution infrastructure.

How it works

Workloads are isolated using Linux sandboxing primitives (`unshare`, `prlimit`). Execution is production-oriented orchestration, not notebook-style run-and-pray.

Workflow Engine

Fault-tolerant execution and coordination layer

Problem

AI workloads need durable scheduling, worker coordination, and failure-aware execution when jobs span multiple nodes and tenants.

What I built

A distributed execution engine using Redis Streams, BullMQ, and Kubernetes to coordinate parallel tasks and isolated workload runs.

How it works

Event-driven coordination with CQRS-like service boundaries — dispatch, execution, and recovery paths evolve independently.

Redis Streams BullMQ Kubernetes CQRS

@xyph3r OSS Suite

Infrastructure-oriented open-source primitives

Problem

Node.js teams keep rebuilding the same reliability primitives — rate limiters, circuit breakers, idempotency layers — from scratch every time.

What I built

An open-source suite of composable infrastructure primitives: rate limiting, idempotency, saga orchestration, and circuit breaking.

How it works

Each package is a standalone, reusable pattern with a clean API. Designed to compose into larger systems rather than being one-off utilities.
